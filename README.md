# JoyigameSDK-Specs

`JoyigameSDK` 的自建 CocoaPods Specs source。

本仓库只保存已发布版本的 podspec，不提交到 CocoaPods Trunk，也不包含 SDK 源码或二进制制品。二进制 zip 由 [JoyigameSDK-Releases](https://github.com/Coke26/JoyigameSDK-Releases) 的 GitHub Releases 提供。

接入时在 `Podfile` 顶部加入：

```ruby
source "https://github.com/Coke26/JoyigameSDK-Specs.git"
source "https://cdn.cocoapods.org/"
```
